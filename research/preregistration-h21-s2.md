### Official sources and scope of support

1. [USGS OFR 2001-502, abstract](https://pubs.usgs.gov/publication/ofr01502): gravity/magnetic profiles over basin-fill faults; gravity evidence was stronger, and aeromagnetics did not resolve minor faults in that Arizona example. This supports NOT requiring a magnetic match. It does not establish our transform or a Great Basin effect size.
2. [USGS / Grauch & Hudson 2007](https://www.usgs.gov/publications/guides-understanding-aeromagnetic-expression-faults-sedimentary-basins-lessons-learned): concealed faults can juxtapose differing magnetic strata, anomaly shape depends on thickness/depth/susceptibility, RTP horizontal gradients help map locations. Examples are Rio Grande rift, not proof for this footprint.
3. [USGS aeroradiometric interpretation background](https://pubs.usgs.gov/of/1999/ofr-99-0016/map_info.html): ratios may indicate lithology, alteration and weathering; warn against survey-boundary interpretations. Alaska NURE sampling/resolution figures MUST NOT be assigned to GeoDAWN.
4. [USGS-authored geothermal imaging paper, abstract/section 1](https://www.osti.gov/servlets/purl/1724108): conductive anomalies can lie on the less-dense/less-magnetic side of potential-field boundaries; conductivity also responds to clays/fluids and needs joint interpretation. Supports H21-7's proposed mechanism, not a universal diagnostic or score prediction.
5. [USGS FDSN event service](https://earthquake.usgs.gov/fdsnws/event/1/): public API parameters for rectangle, time, event type, magnitudes and output format. Use a frozen historical window 2000-01-01 through 2026-09-29, exact footprint-bounding-box query and earthquake-only type. One limited schema probe is not a complete event catalogue. A runner retrieval will check obtainability before calling H21-8 viable.
6. [Official INGENIOUS release / CC BY 4.0](https://gdr.openei.org/submissions/1391): v2 supersedes v1, provides fault geometry/attributes and separate seismicity data. License requires attribution. The release is provided as-is.
7. [Official DTI and TIFF format](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/) and [staff masking clarification](https://community.drivendata.org/t/scoring-clarification-are-known-usgs-ingenious-faults-masked-when-scoring-and-are-they-in-the-final-round-label-set/11516/4). ## Fixed H21-5 feature contract

* No catalogue-derived predictor or whole-catalogue model field. Raw source invalid/sentinel cells remain missing, not zero evidence.
* Per field, Gaussian normalized smoothing at sigma 1 and 3 pixels, truncate 4. Require .99 valid smoothing support, one-gradient-neighbour margin, and valid samples at every requested profile position. Unit normal is that field's gradient normal, undefined gradients give zero strength.
* For sigma s, sample smoothed field at normal offsets -3s, -s, 0, +s, +3s. Signed increments have one direction; central gradient must exceed each outer gradient. A linear ramp is not a concentrated step. Shape contrast is clipped to [0,1].
* Compute finite-difference Hessian of the smoothed field. Evaluate normal curvature at offsets -s and +s with the same centre normal. Curvatures must oppose and have step-compatible sign. Balance = 2 min(|c_left|,|c_right|)/(|c_left|+|c_right|+1e-12).
* Step strength = log1p(gradient amplitude per 100m) × concentration × balance. For each field save sigma-1 strength, sigma-3 strength, and geometric-mean persistence. Six extra channels total; no feature/band/scale/budget sweep. Toy invariants must pass before any real-label outcome.
* Physical emission strength for BOTH control and candidate is max of the four existing per-field gradient-amplitude channels, valid source support required. Strength is a nonzero physical-amplitude guard, not proof of a fault. Candidate-only step features must not change the paired eligible domain/budget.
